# Security Policy

## Supported versions

Security fixes are prepared for the latest release and the current `main`
branch. Older releases may not receive backports.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
private **Report a vulnerability** form in the repository Security tab. If
that form is unavailable, contact the repository owner privately through
GitHub before disclosing details.

Include the affected revision, impact, reproduction steps, and any suggested
mitigation. Do not include credentials, signed transactions, peer-private
data, or other secrets in a report.
